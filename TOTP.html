totp

A simple and secure CLI tool for macOS to generate Time-based One-Time Passwords (TOTP)

Download v1.1.0 (.pkg) GitHub

USAGE

Run totp in Terminal and enter your secret key:

$ totp

Enter Secret Key:

25s remaining : 123456

/ INSTALLATION & UNINSTALLATION

Installation

  1. Download totp-1.1.0.pkg from the Releases page
  2. Open the pkg installer to install totp to /usr/local/bin

Uninstallation

To remove totp from your system, run the uninstallation script in Terminal:

sudo uninstall-totp
